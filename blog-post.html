A web is a window manager.

Why horizontal strips beat vertical scroll for dense, keyboard-first content — and what Niri taught me about the browser as a compositor.

SH
Saim Hashmi @saim
Fedora 42 · Niri · GMT+1

The tiling window manager solved a problem the browser still has: how to let many things live on the screen without forcing the user to juggle them. Niri takes this further with a scrollable strip — windows live in an infinite row, and focus moves spatially rather than through a stack.

This site is an attempt to answer a simple question. If the browser is a window manager, what does a portfolio look like? Not a vertical document to be consumed top-to-bottom, but a workspace. You walk through it. Focus is a place.

The document metaphor is tired

Vertical scroll made sense when a web page was a newspaper article with hyperlinks. It does not make sense for a technical portfolio where the content is modular — some is read, some is referenced, some is just looked at. Treating every section as a "fold" we punish the reader to descend through is an artifact of print, not a native idea.

// niri.kdl — the window manager's config is readable prose
layout {
    gaps 16
    preset-column-widths {
        proportion 0.33333
        proportion 0.5
        proportion 0.66667
    }
}

Horizontal as narrative

When content flows left-to-right, there is an implicit sequence. You don't scroll past things; you move through them. The scroll budget of a column becomes its story arc. This is how animated film works, and how comics work. The browser knows how to do this — it has just chosen not to.

"The screen is not a page. The scroll is not a turn. A compositor is a narrative engine we've been using to open Slack."

What Niri taught me

  1. Focus is spatial. The active window has a place. You can return to it.
  2. Content is dense. Three columns at once is more information than one.
  3. Keyboard is first. Every interaction has a shortcut; mouse is a fallback.
  4. State is visible. You always know where you are in the strip.

On interpretation

This isn't a Niri clone in the browser. That would be both impossible and uninteresting. It's a translation — the shape of Niri's ideas, expressed through the affordances the web actually has: pinned ScrollTrigger, GSAP timelines, CSS grid. The terminal that boots this site is there to announce the aesthetic commitment. Everything that follows is a rice.
